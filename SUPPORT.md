# Getting help

MK8DX Ecosystem is a hobby project maintained by one person. Help is given on a best-effort basis.

1. **Read the guide for what you are doing.** The [README](README.md#get-started) routes you to the guide for
   hosting a server, running Tournament nights, using the website and the Android app, LiveTrial, or
   development. [Operations](docs/OPERATIONS.md) covers backups, upgrades and restores, and
   [Development](docs/DEVELOPMENT.md#troubleshooting) lists common setup problems. The user guides attached
   to every release (`MK8DX_User_Guide_EN` and `MK8DX_Handleiding_NL`, as `.txt` and `.docx`) are the offline,
   printable copy for people without the website at hand, not a separate starting point.
2. **Search the existing issues**, including closed ones.
3. **Open an issue** with the bug report or feature request template. Say which product and version you use
   (website, Android app, LiveTrial, Tournament tools, or the server package and its installation route),
   what you did, what you expected and what happened.

Keep issues free of personal and private data: no passwords, sign-in links, session cookies, `secrets.json`,
database backups, recordings, or other players' names. Use synthetic examples. A maintainer who needs a
diagnostic will ask for a narrowly redacted one.

**Security problems** are never reported in a public issue: follow [SECURITY.md](SECURITY.md).

A community that runs its own server supports its own players: players of such an installation should first
ask the people who run it.
