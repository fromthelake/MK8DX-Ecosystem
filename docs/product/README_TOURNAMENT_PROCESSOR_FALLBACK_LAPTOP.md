# Tournament Processor on a local laptop

Extract the full package and run `Install-MK8DX-TournamentTools.cmd`. Drop a
recorded tournament video on `TournamentProcessor.cmd`; inspect the Excel/CSV
output and canonical JSON in the adjacent session folder. Correct uncertain OCR
through the product review flow before importing the JSON into Tournament
Manager. Import creates pending evidence; director acceptance is separate.
The installed package already contains recorded recognition assets and schema-9
display data. Keep the input video and session output in operator storage.
See [Tournament Tools](USING_MK8DX_TOURNAMENT_TOOLS.md).
