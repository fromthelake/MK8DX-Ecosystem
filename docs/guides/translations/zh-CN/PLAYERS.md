# 玩家：网站和 Android 应用

*本文是[英文版指南](../../PLAYERS.md)的机器翻译，以英文版为准。欢迎通过“Translation correction”问题表单提交更正。*

[所有指南](../../../../README.md#get-started)

你需要知道你所在社区的 MK8DX 网站地址，例如 `https://www.example.org`。每个社区
都运行自己的安装，拥有自己的账户和成绩；请向负责你所在社区的人索取地址，
并请他们帮助你处理账户问题。使用网站不需要安装任何东西。

## 网站

### 登录

1. 打开你所在社区的地址，选择账户图标（右上角），然后选择 **登录**。
2. 输入你的电子邮件地址，然后选择 **通过电子邮件发送链接**。打开邮件并点击其中的链接。没有
   密码。链接只能使用一次，并且会过期；如果它不能用，请再申请一个新的。
3. 第一次登录时，链接会直接打开一个分三步的设置。第 1 步 **你已经在本网站上了吗？**
   会询问你的计时赛成绩是否已经在网站上，以及你是否参加过网站上列出的锦标赛。
   如果是，第 2 步让你找到代表你本人的玩家，并申请把它关联到你的账户；在关联之前，
   管理员或当晚的赛事总监会审核这样的认领，而且绝不会仅凭名字就进行关联。如果不是，
   第 2 步会创建你的玩家（在只有赛事总监才能创建玩家的社区中，它会说明你应该去找谁）。
   第 3 步提供一些可以跳过的可选设置。

你的账户（你用来登录的电子邮件）和你的玩家（排行榜上的名字）是两个不同的东西。

### 提交计时赛成绩

- **提交时间**（顶部栏），或 **赛道** → 一条赛道 → **提交时间**：输入你在 150cc 或 200cc 的时间，在确认页面上
  检查各项数值，然后发布。
- **扫描**：在手机或平板上打开 `<your community address>/scanner/`。把相机对准电视上的成绩
  画面，或者选择 **图片上传** 并使用一张照片或截图。扫描器会读取时间、每圈成绩，
  以及在可见时读取角色、车辆组合和国旗。提交之前请检查每一项数值；识别结果可能
  有误。相机需要受信任的 HTTPS 地址（在 `localhost` 上也可以使用）；图片上传在任何地方都可以使用。
- 根据社区的规则，提交的成绩可能会立即发布，也可能需要等待管理员
  审核。管理员可以更正或撤回已发布的成绩。

### 关注你的进步

**赛道**、**排名** 和 **纪录** 会把你的最佳时间和单圈成绩与社区、你选择的对手、
任天堂工作人员幽灵以及世界纪录放在一起显示。**组合** 帮助你搭配角色和车辆，**社区**
显示其他玩家，**锦标赛** 显示已发布的锦标赛之夜、排名和报告。当有人
打破你的某个已发布成绩时，你会收到一条通知（铃铛）。如果你的社区已经设置好，网站还可以发送浏览器推送
通知；请在你的账户设置中打开它们。

网站提供游戏的全部 15 种语言（在设置中选择你的语言）。英语和荷兰语经过
审校；其他 13 种是机器翻译，欢迎提交更正：要编辑的文件见
[Change UI text and translations](../../../DEVELOPMENT.md#change-ui-text-and-translations)，
拉取请求的方法见 [Contributing](../../../../.github/CONTRIBUTING.md)。

## Android 应用

应用可以直接在手机上进行更快的扫描，并显示你的成绩和通知。它是可选的。

### 要求

- Android 8.0 或更新版本；建议使用 arm64 手机。正式版 APK 很大（大约 530 MB）：安装时请保留大约
  1 GB 的可用空间。
- 一个应用能够访问的社区：使用受信任 HTTPS 地址的 **在线社区**，或者同一 Wi-Fi 中的
  **家庭或俱乐部安装**（A2）。仅限本机的地址（`http://127.0.0.1:…`）在应用中无法使用。

### 安装

1. 如果你所在社区的 **获取应用** 页面提供下载，就从那里获取 APK（你必须登录才能看到
   下载；那是你的社区所支持的版本），或者从项目的
   [GitHub Releases](https://github.com/fromthelake/MK8DX-Ecosystem/releases) 页面获取：选择
   `mk8dx-android-release-….apk`。如果你有代码仓库的克隆，也可以自己构建 APK：
   [Client builds](../../../CLIENT_BUILDS.md#android)。
2. 用同一版本中的 `SHA256SUMS.txt` 检查这个文件（在电脑上：PowerShell 中用 `Get-FileHash`，
   Linux 上用 `sha256sum`，macOS 上用 `shasum -a 256`）。
3. 把 APK 复制到手机上，并从 **文件** 或 **下载** 中打开它。Android 会询问是否允许从
   那个应用安装；只为这个已检查的文件允许，如果你愿意，之后可以再关闭它。

这不是 Play 商店应用。早期的公开 APK 使用调试构建密钥签名；正式版 APK 使用
维护者长期保留的密钥。安装这个正式版之前，请先保存所有尚未发送的成绩，并卸载一次早期的调试版
APK。以后用同一个正式密钥签名的 APK 可以直接覆盖更新。切换到某个社区提供的或
自行构建的、使用不同密钥的 APK 时，同样需要先卸载。

### 首次启动

应用会以 **选择你的社区** 打开；如果应用支持手机的语言，就使用手机的语言。要选择其他
语言，请点按顶部的 **语言 / Language**（带地球图标）；应用会记住这个选择。然后它只问一件事：
你的社区怎么玩。不确定？请询问
负责你所在社区的人。

- **在家或在俱乐部**（A2，MK8DX 运行在那里的一台电脑上）：点按 **扫描二维码**，扫描你的管理员在那台电脑上显示
  或用纸分发的 **Prepare a device**（准备设备）卡片。手机必须连接到
  同一个 Wi-Fi。应用随后会显示该安装的地址和密钥；它们也显示在 **Prepare this
  device**（准备此设备）页面的 **Full fingerprints**（完整指纹）下。两者一致时点按 **连接**。不需要互联网。分步说明：
  [A2 指南第 7 章](../../../install/translations/zh-CN/A2_HOME_GUIDE.md#7-android-应用和-livetrial)。
- **在线社区**（互联网上的网站）：输入你在浏览器中打开它时使用的地址，例如
  `https://www.example.org`（不带路径，不带末尾的斜杠），然后点按 **保存**。如果失败，请在
  手机浏览器中打开同一个地址：它必须能够打开，并且没有证书警告。

在家或俱乐部（A2），先核对 16 位安装验证码并点按 **连接**。然后按应用步骤操作：**保存证书**、**打开设置** 将其安装为 CA 证书，再点按 **扫描登录卡** 在应用内登录。无需浏览器设备代码。对于在线社区，请点按人像图标和 **登录**，然后在浏览器中批准。

### 熟悉界面

应用顶部显示标志（返回首页）、显示你正在使用的社区名称的 **社区标签**、
铃铛和你的名字。你的名字会打开 **你**：其中有你的玩家和 **切换玩家**，以及
**我的成绩**、**纪录** 和 **对手** 这几个标签页，下方还有一行 **设置**。

- **多个社区**：点按社区标签打开 **社区**。当前使用的社区显示为绿色；**切换社区**
  一键换到另一个社区，**从此手机移除** 会忘记一个社区（只有在没有待发送内容时才可以），
  **添加社区** 会再次打开首次启动界面。每个社区都保留各自的登录、各自尚未发送的
  成绩，以及（在家或在俱乐部时）各自的信任关系；它们之间不会自行转移任何内容。当管理员
  为社区命名后，应用会显示这个名字，而不是地址。
- **我的成绩** 是一个列表：先是你的生涯数据，然后每条赛道和每个级别各占一行，显示你的个人最佳成绩；点按
  某一行可查看较早的成绩，在某个成绩上使用 **⋯** 可以选择 **详情**、**编辑**、**撤回** 或
  **带到另一个社区…**。
- **没有互联网时**：应用会按社区保存一份你自己的成绩和你的对手的最佳成绩，
  并显示“离线 — 最后更新 …”。
- **等待发送**：仍然只保存在手机上的成绩会在首页和“你”页面上显示为橙色横幅；点按它，
  或者使用设置 › **保存在此手机上** 来查看它们。
- **设置** 分为 **玩家**、**应用**、**社区** 和 **关于** 几组，每项更改都会自动保存。
  语言位于“应用”下；**获取应用** 和 **保存在此手机上** 位于“社区”下；**运行测试扫描**
  位于“关于”下。

### 把成绩带到另一个社区

如果你属于多个社区，一个成绩也可以在另一个社区中计入：在某个成绩上使用 **带到另一个社区…**，
或者在“我的成绩”中生涯数据下方使用 **带走我的最佳成绩**（另一个社区中
你已有更好成绩的赛道会被跳过）。在你登录那个社区之前，这份副本会一直等待。由 **接收方**
社区决定：默认情况下它不接受来自别处的成绩，它也可以让管理员先逐一审核，
或者像对待其他成绩一样接受它们。带来的成绩总会显示它来自哪里（“带自 … ·
原始日期 …”）。同一个原始成绩只会被接受一次；相同的时间只会补全现有成绩中
缺少的信息。

### 通知

应用中的通知是从你所在社区的收件箱中获取的；Android 的通知权限和
应用自身的开关都必须打开。

## 问题

- 收不到登录邮件：检查垃圾邮件、确认地址准确无误，并申请一个新链接。在本地试用安装中，
  邮件会发送到本地测试收件箱，而不是你的邮箱。
- 认领被拒绝并显示 *目前认领操作过多…*：等待提示的时间后重试。一个账号同时最多可以有 5 个等待决定的认领（一个玩家最多 5 个，所有账号合计）。达到上限时，请等待某个待处理的认领被处理，或用 **撤回此请求** 撤回一个，然后重试。
- 你所在社区的网站上有什么看起来不对：请先询问负责它的人。软件本身的错误
  可以在项目的问题（issues）中报告；见 [SUPPORT.md](../../../../.github/SUPPORT.md)。绝不要发布登录链接或他人的
  名字。
