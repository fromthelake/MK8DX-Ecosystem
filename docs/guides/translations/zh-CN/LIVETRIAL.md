# LiveTrial：在 Windows 上记录计时赛

*本文是[英文版 LiveTrial 指南](../../LIVETRIAL.md)的机器翻译，以英文版为准。欢迎通过“Translation correction”问题表单提交更正。*

[所有指南](../../../../README.md#get-started) · [LiveTrial 组件 README](../../../../apps/timetrials-desktop/README.md)

LiveTrial 是一个 Windows 程序，它通过采集卡观看你的计时赛，或者读取录好的视频，
识别每一次跑出的成绩（总时间和单圈时间、角色和车辆组合、幽灵），并连同一段片段保存在你的电脑上。
登录一次之后，它可以把成绩发送到你所在社区的网站。暂时无法发送的成绩会
在电脑上等待。

## 没有社区网站时

LiveTrial 也可以单独使用。采集、视频分析、**成绩历史**、片段和更正都在本地进行。
没有账户时记录的成绩只保存在这台电脑上，直到你用 **以 <account> 身份发送** 把它们发送出去。
**我的纪录**、**名次** 和 **组合** 标签页需要一个已登录的社区。

## 要求

- x86-64 的 Windows（已在 Windows 11 上测试）。程序本身大约需要 1 GB，另外还要为你的录像留出空间。
- 实时采集：一张 Windows 会列为视频设备的采集卡及其驱动程序，以及 **FFmpeg**（免费，
  因许可证原因未包含在内；见下面第 4 步）。只使用视频文件时：不需要采集卡，也不需要 FFmpeg。
- 发送成绩：你所在社区网站的地址以及在那里的账户（见 [玩家](PLAYERS.md)）。
  在装有本地试用安装的同一台电脑上，`http://127.0.0.1:<port>` 可以使用；其他情况请使用受信任的
  HTTPS 地址。

## 安装

1. 从项目的 [GitHub Releases](https://github.com/fromthelake/MK8DX-Ecosystem/releases) 页面（每个版本都附有
   发布包）下载 `desktop-client-….zip` 和 `SHA256SUMS.txt`。如果你有代码仓库的克隆，
   也可以自己构建同样的包：[Client builds](../../../CLIENT_BUILDS.md#livetrial-windows)。在 PowerShell 中检查它：
   运行 `Get-FileHash '.\desktop-client-<version>.zip' -Algorithm SHA256` 并比较完整的值。
2. 把 **整个** ZIP 解压到一个属于你的文件夹，例如“文档”下。保持它的文件夹结构；
   这个包自带 Python 运行时、识别引擎和游戏素材。
3. 双击 `LiveTrial.exe`。仪表板会以单独的窗口打开（优先 Edge，其次 Chrome，否则使用你的默认
   浏览器）。分析视频立即就能使用。
4. 要进行实时采集，请安装一次 FFmpeg。最简单的方法：打开 PowerShell 并运行 `winget install Gyan.FFmpeg`，
   然后退出并重新启动 LiveTrial，让它识别新的 PATH。没有 winget 时，请下载一个 Windows 构建（例如
   从 [ffmpeg.org/download.html](https://ffmpeg.org/download.html) 链接的 gyan.dev 发布 zip），解压后
   把 `bin\ffmpeg.exe` 复制到 `%LOCALAPPDATA%\MK8DX\LiveTrial\tools\ffmpeg\bin\`。如果缺少 FFmpeg，
   **开始采集** 会提示这一点并显示这些步骤。

## 连接到你的社区

1. 打开 **设置**。在 **社区网站地址** 中输入你所在社区的地址（例如
   `https://www.example.org`），然后选择 **保存服务器**。LiveTrial 会自行重新启动；请让它保持打开。
2. 重新启动后，检查设置中显示的地址是否与你的地址完全一致，然后从账户菜单登录（电子邮件
   验证码、电子邮件链接或在网站上批准）。
3. 如果自动重新启动失败，请在应用中选择 **退出 LiveTrial**，等它完全关闭，然后再次启动
   `LiveTrial.exe`。只关闭窗口是不够的：LiveTrial 可能会在后台继续运行。

账户和等待发送的成绩按服务器分别保存：切换服务器绝不会把旧成绩发送到新的
社区。绝不要在 LiveTrial 中输入本地邮件收件箱地址或服务器的内部地址。

## 以后再连接

你可以先记录，以后再加入一个社区。已经在这台电脑上的成绩会这样处理：

- **在记录之前选择社区。** 成绩按服务器保存。在你保存社区地址之前记录的成绩，或者在
  设置了另一个社区时记录的成绩，会留在那个服务器下，绝不会提供给新的
  社区。要把这样的录像带过来，请在连接之后对它的视频文件再次运行 **分析视频**。
- **没有账户时记录的成绩** 在你以后登录时不会被发送。在某一条成绩上（在 **成绩历史** 中或
  比赛后的那一行上），或在等待列表（顶部的计数器）的 **无账户** 一行上选择 **以 <account> 身份发送**，
  就会把它们全部交给已登录的账户。它们会归入该账户的玩家；不做这个选择，
  就不会分配任何成绩。
- **登录时记录的成绩** 总是用同一个账户发送。**立即发送** 会发送所有等待中的成绩，
  每条成绩用它自己的账户；如果某条成绩的账户已退出登录，它会等到那个账户再次登录。
- **每条成绩只保存一次。** 每条成绩都带有自己的提交 ID，网站不会接受同一条成绩的第二份
  副本。
- **片段和视频留在这台电脑上。** 只有成绩（时间、赛道、组合）会发送到网站；上传到 YouTube
  是另一个可选的步骤。

## 使用

- **开始采集**：选择采集卡。LiveTrial 会先显示它的一张静态画面，让你检查
  这是不是正确的设备。然后 **实时** 标签页会显示画面和每一条识别出的成绩。
- **分析视频**：选择一个 `.mp4`/`.mkv` 文件（它会被复制到
  `%LOCALAPPDATA%\MK8DX\LiveTrial\videos`），LiveTrial 会像处理采集一样处理它。
- 每场比赛结束后，**上一场比赛** 一行会说明这条成绩在哪里：已在网站上、已保存并等待发送
  （**立即发送**），或者只在这台电脑上（**以 <account> 身份发送**）。
- **成绩历史** 列出每一条成绩及其片段。你可以更正识别结果；更正会保存一个新
  版本，并保留之前的版本。
- 自动发送默认是关闭的；请在设置中打开它。成绩总是先保存在本地。

当主机语言与仪表板语言不同时，请在设置中设置 **你的 Switch 语言**。

## 问题

- 网站不对，或者登录时打开了错误的网站：用 **退出 LiveTrial** 退出 LiveTrial，再次启动它，并检查
  设置中的地址。同一台电脑上的另一个 Windows 账户可能仍在运行 LiveTrial。
- 没有列出采集设备：检查 USB 连接和驱动程序，等几秒钟后再试一次。
- 识别错误：在发送之前，请在成绩历史中更正这条成绩。识别永远不能代替
  你亲自检查自己的成绩。

LiveTrial 仅支持 Windows；没有 macOS 或 Linux 版本。要自己构建，请见
[Client builds](../../../CLIENT_BUILDS.md)。
