# LiveTrial：在 Windows 上記錄計時賽

*本文是[英文版 LiveTrial 指南](../../LIVETRIAL.md)的機器翻譯，以英文版為準。歡迎透過「Translation correction」問題表單提交更正。*

[所有指南](../../../../README.md#get-started) · [LiveTrial 元件 README](../../../../apps/timetrials-desktop/README.md)

LiveTrial 是一個 Windows 程式，它透過擷取卡觀看你的計時賽，或讀取錄好的影片，
辨識每一次跑出的成績（總時間和單圈時間、角色和車輛組合、幽靈），並連同一段片段儲存在你的電腦上。
登入一次之後，它就能把成績傳送到你所在社群的網站。暫時無法傳送的成績會
在電腦上等待。

## 沒有社群網站時

LiveTrial 也可以單獨使用。擷取、影片分析、**成績記錄**、片段和更正都在本機進行。
沒有帳號時記錄的成績只會保存在這台電腦上，直到你用 **以 <account> 身分傳送** 把它們傳送出去。
**我的紀錄**、**排名** 和 **組合** 分頁需要一個已登入的社群。

## 需求

- x86-64 的 Windows（已在 Windows 11 上測試）。程式本身大約需要 1 GB，另外還要為你的錄影保留空間。
- 即時擷取：一張 Windows 會列為視訊裝置的擷取卡及其驅動程式，以及 **FFmpeg**（免費，
  因授權因素未包含在內；請見下方第 4 步）。只使用影片檔案時：不需要擷取卡，也不需要 FFmpeg。
- 傳送成績：你所在社群網站的網址以及在那裡的帳號（請見 [玩家](PLAYERS.md)）。
  在裝有本機試用安裝的同一台電腦上，`http://127.0.0.1:<port>` 可以使用；其他情況請使用受信任的
  HTTPS 網址。

## 安裝

1. 從專案的 [GitHub Releases](https://github.com/fromthelake/MK8DX-Ecosystem/releases) 頁面（每個版本都附有
   發行套件）下載 `desktop-client-….zip` 和 `SHA256SUMS.txt`。如果你有程式碼儲存庫的複製，
   也可以自己建置同樣的套件：[Client builds](../../../CLIENT_BUILDS.md#livetrial-windows)。在 PowerShell 中檢查它：
   執行 `Get-FileHash '.\desktop-client-<version>.zip' -Algorithm SHA256` 並比對完整的值。
2. 把 **整個** ZIP 解壓縮到一個屬於你的資料夾，例如「文件」底下。保留它的資料夾結構；
   這個套件自帶 Python 執行環境、辨識引擎和遊戲素材。
3. 按兩下 `LiveTrial.exe`。儀表板會以獨立的視窗開啟（優先 Edge，其次 Chrome，否則使用你的預設
   瀏覽器）。分析影片馬上就能使用。
4. 若要即時擷取，請安裝一次 FFmpeg。最簡單的方式：開啟 PowerShell 並執行 `winget install Gyan.FFmpeg`，
   然後結束並重新啟動 LiveTrial，讓它讀到新的 PATH。沒有 winget 時，請下載一個 Windows 建置版本（例如
   從 [ffmpeg.org/download.html](https://ffmpeg.org/download.html) 連結的 gyan.dev 發行 zip），解壓縮後
   把 `bin\ffmpeg.exe` 複製到 `%LOCALAPPDATA%\MK8DX\LiveTrial\tools\ffmpeg\bin\`。如果缺少 FFmpeg，
   **開始擷取** 會提示這一點並顯示這些步驟。

## 連線到你的社群

1. 開啟 **設定**。在 **社群網站地址** 中輸入你所在社群的網址（例如
   `https://www.example.org`），然後選擇 **儲存伺服器**。LiveTrial 會自行重新啟動；請讓它保持開啟。
2. 重新啟動後，確認設定中顯示的網址與你的網址完全一致，然後從帳號選單登入（電子郵件
   驗證碼、電子郵件連結或在網站上核准）。
3. 如果自動重新啟動失敗，請在 App 中選擇 **結束 LiveTrial**，等它完全關閉，然後再次啟動
   `LiveTrial.exe`。只關閉視窗是不夠的：LiveTrial 可能會在背景繼續執行。

帳號和等待傳送的成績會依伺服器分開保存：切換伺服器絕不會把舊成績傳送到新的
社群。絕不要在 LiveTrial 中輸入本機郵件收件匣的地址或伺服器的內部網址。

## 稍後再連線

你可以先記錄，之後再加入一個社群。已經在這台電腦上的成績會這樣處理：

- **在記錄之前選擇社群。** 成績會依伺服器保存。在你儲存社群網址之前記錄的成績，或在
  設定了另一個社群時記錄的成績，會留在那個伺服器底下，絕不會提供給新的
  社群。若要把這樣的錄影帶過來，請在連線之後對它的影片檔案再次執行 **分析影片**。
- **沒有帳號時記錄的成績** 在你之後登入時不會被傳送。在某一筆成績上（在 **成績記錄** 中或
  比賽後的那一行上），或在等待清單（頂端的計數器）的 **無帳號** 那一行上選擇 **以 <account> 身分傳送**，
  就會把它們全部交給已登入的帳號。它們會歸入該帳號的玩家；沒有做這個選擇，
  就不會分配任何成績。
- **登入時記錄的成績** 一律用同一個帳號傳送。**立即傳送** 會傳送所有等待中的成績，
  每一筆都用它自己的帳號；如果某一筆成績的帳號已登出，它會等到那個帳號再次登入。
- **每一筆成績只會保存一次。** 每一筆成績都帶有自己的提交 ID，網站不會接受同一筆成績的第二份
  副本。
- **片段和影片會留在這台電腦上。** 只有成績（時間、賽道、組合）會傳送到網站；上傳到 YouTube
  是另一個選用的步驟。

## 使用

- **開始擷取**：選擇擷取卡。LiveTrial 會先顯示它的一張靜態畫面，讓你確認
  這是正確的裝置。接著 **直播中** 分頁會顯示畫面和每一筆辨識出的成績。
- **分析影片**：選擇一個 `.mp4`/`.mkv` 檔案（它會被複製到
  `%LOCALAPPDATA%\MK8DX\LiveTrial\videos`），LiveTrial 會像處理擷取一樣處理它。
- 每場比賽結束後，**上一場比賽** 那一行會說明這筆成績在哪裡：已在網站上、已儲存並等待傳送
  （**立即傳送**），或只在這台電腦上（**以 <account> 身分傳送**）。
- **成績記錄** 列出每一筆成績及其片段。你可以更正辨識結果；更正會儲存一個新的
  版本，並保留之前的版本。
- 自動傳送預設為關閉；請在設定中開啟它。成績一律會先儲存在本機。

當主機語言與儀表板語言不同時，請在設定中設定 **你的 Switch 語言**。

儀表板只能在這台電腦上操作：在 LiveTrial 視窗中，或在此電腦上開啟的儀表板頁面中。如果引擎以 `--lan` 啟動（請見 [LiveTrial 元件 README](../../../../apps/timetrials-desktop/README.md)），網路中的手機和平板可以觀看即時檢視和成績紀錄，但無法變更任何內容。

## 易讀的片段名稱

在 LiveTrial 內部，片段保留其內部名稱。每個完成的片段也會出現在同一個資料夾
`文件\MK8DX\LiveTrial-clips`（磁碟上為 `Documents\MK8DX\LiveTrial-clips`）中，名稱一目瞭然：

```
2026-11-16 10h25m  Mario Kart Stadium  150cc  1m46s784.mp4
```

- 片段開始的日期和時刻（這台電腦的時鐘）、賽道、等級（50cc、100cc、150cc、200cc 或 Mirror）和成績，各欄位之間
  以兩個空格分隔。用錄製按鈕錄下的片段稱為 `Manual`，幽靈重播稱為 `Ghost <賽道>`。LiveTrial 沒有辨識出的賽道或
  成績會被省略（`Unknown track`），絕不猜測。名稱已被使用時會加上 ` (2)`。
- 檔名只使用英文字母、數字、空格和 `-`，因此 LiveTrial 使用中文時，賽道名稱為英文。撇號等符號會被移除
  （Yoshi's Circuit 變為 Yoshis Circuit）。
- 與 LiveTrial 資料在同一磁碟上時，它是硬連結，不佔用額外空間；在其他磁碟上則是副本。LiveTrial 的儲存清理刪除某個
  片段時，它的易讀副本也會一併刪除；已釘選的片段保留其副本。
- **成績記錄** 在片段下方顯示該名稱，並附有 **Open folder** 按鈕。在 **設定** 的 **易讀的片段副本** 中可以關閉副本或
  選擇其他資料夾。

副本在片段完成後於背景產生。如果失敗（例如無法存取該資料夾），片段本身不受影響。

## 問題

- 網站不對，或登入時開啟了錯誤的網站：用 **結束 LiveTrial** 結束 LiveTrial，再次啟動它，並檢查
  設定中的網址。同一台電腦上的另一個 Windows 帳號可能仍在執行 LiveTrial。
- 沒有列出擷取裝置：檢查 USB 連線和驅動程式，等幾秒後再試一次。
- 辨識錯誤：在傳送之前，請在成績記錄中更正這筆成績。辨識永遠不能取代
  你親自檢查自己的成績。

LiveTrial 只支援 Windows；沒有 macOS 或 Linux 版本。若要自己建置，請見
[Client builds](../../../CLIENT_BUILDS.md)。
