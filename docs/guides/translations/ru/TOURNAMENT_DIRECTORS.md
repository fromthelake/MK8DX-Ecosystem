# Tournament Directors: проведение турнирного вечера

*Это машинный перевод [английского руководства](../../TOURNAMENT_DIRECTORS.md); основной считается английская версия. Исправления приветствуются через форму issue «Translation correction».*

[Все руководства](../../../../README.md#get-started) · [Справочник по Tournament Tools](../../../product/USING_MK8DX_TOURNAMENT_TOOLS.md)

Tournament Director (директор турнира) проводит турнирный вечер на сайте сообщества: участники, консоли, группы,
очки, финалы и опубликованный отчёт. **Tournament Tools** для Windows умеют считывать результаты гонок из записей
или захвата в реальном времени, так что вам не нужно вводить каждое место вручную. Они необязательны: очки можно
также ввести вручную или импортировать из Excel/CSV.

**Без сайта:** Tournament Tools для Windows из [раздела 3](#3-tournament-tools-для-windows) (Processor,
Analysis и Live) работают сами по себе. Они записывают файлы Excel, CSV и JSON на ваш ПК; Connect необязателен.

Распознавание никогда не делает результат официальным. Вы проверяете каждую гонку, прежде чем она будет засчитана, и вы решаете о публикации.

## 1. Получите права директора на сайте вашего сообщества

1. Войдите на сайт (см. [Игроки](PLAYERS.md)).
2. На странице **Турниры** выберите **Запросить право проводить**. Администратор одобряет или отклоняет запрос.
   Администраторы, а также директора после одобрения не видят эту кнопку: они видят **Создать новый турнир** на
   той же странице (на панели **Управление гонкой**) и начинают вечер оттуда.
3. Чтобы отправлять распознанные гонки из инструментов для Windows на сайт, администратор также даёт вашему игроку,
   под которым выполнен вход, доступ в разделе **Администрирование → Турниры → Директора**. Это даёт доступ к турнирам,
   а не общие права администрирования.

## 2. Проведение вечера на сайте

Откройте турнир на странице **Турниры** (администраторы также попадают к нему через **Администрирование → Турниры**).
Вечер — это последовательность шагов; страница показывает, где вы находитесь:

| Шаг | Что вы делаете |
| --- | --- |
| 0 | Выберите директора |
| 1 | Начните турнир |
| 2 | Выберите участников, отметьте, кто присутствует и какие Switch они приносят (галочки **NS1**/**NS2** рядом с каждым именем) |
| 3-4 | Создайте и экспортируйте схему квалификации (группы и рассадку) |
| 5 | Введите очки квалификации: вручную, из файла Excel/CSV или из **Входящие результаты** |
| 6 | Экспортируйте результаты квалификации |
| 7-8 | Проверьте и экспортируйте финальные группы |
| 9 | Введите очки финальных групп; импорт работает по группам и отклоняет группу, пока какое-либо имя ещё не сопоставлено |
| 10 | Завершите и поделитесь: итоговая таблица, отчёт и экспорт для WordPress |

Шаг 2 продолжается, только когда консолей Switch достаточно: за каждой Switch сидят два игрока, поэтому вечеру нужно
не меньше половины присутствующих участников, с округлением вверх, в отмеченных Switch (9 присутствующим игрокам нужно 5).
Блок готовности под списком показывает, сколько не хватает; отметьте Switch, которые приносят люди, или переведите
участников в **Лист ожидания** или **Отсутствует**.

Для гонок, пришедших из Tournament Tools: откройте **Входящие результаты** для группы, сопоставьте каждое распознанное
имя с нужным игроком, проверьте трассу и места на финише и выберите **Подтвердить**. Предварительная таблица Live
не является официальным результатом. Вы также можете напрямую импортировать файл результатов через **Запасной офлайн-вариант:
импортировать сохранённый файл результатов Live / Processor** внутри группы или через **Администрирование → Турниры → Импорт канонических результатов гонок**.

Публикация и рейтинг сообщества — отдельные решения на последнем шаге.

## 3. Tournament Tools для Windows

### Требования

- Windows на x86-64 (проверено на Windows 11) и несколько ГБ свободного места. ZIP занимает около 450 МБ, а в распакованном виде около 1,3 ГБ;
  установщику один раз нужен интернет, чтобы скачать Python 3.12 и общедоступные пакеты (больше с GPU/CUDA); все модели OCR
  включены. После установки обработка работает офлайн. Видеокарта NVIDIA
  ускоряет только шаг OCR; первое сканирование записи всегда выполняется на CPU (см.
  [which steps use the graphics card](../../../product/USING_MK8DX_TOURNAMENT_TOOLS.md#which-steps-use-the-graphics-card)).
- Для захвата в реальном времени: карта захвата с работающим драйвером Windows (DirectShow). Для записей: ничего дополнительного.
- Необязательно, для отправки результатов: адрес сайта и доступ оператора турниров (шаг 1).

### Установка

1. На странице [GitHub Releases](https://github.com/fromthelake/MK8DX-Ecosystem/releases) проекта (пакеты прикреплены
   к каждому релизу) скачайте `tournament-tools-….zip` и `SHA256SUMS.txt`. Имея клон, вы можете вместо этого
   собрать его сами ([Сборка инструментов самостоятельно](#сборка-инструментов-самостоятельно)). В PowerShell:
   `Get-FileHash '.\tournament-tools-<version>.zip' -Algorithm SHA256`, и сравните значение целиком.
2. Распакуйте весь ZIP в папку с правом записи (не в `Program Files`). Держите `runtime-assets\` рядом с
   файлами запуска.
3. Дважды щёлкните `Install-MK8DX-TournamentTools.cmd` и дождитесь `SUCCESS`. Он сам выбирает NVIDIA CUDA или PyTorch
   для CPU для этого компьютера. Если установка не удалась, прочитайте `install.log` в папке пакета.

Установщик создаёт такие файлы запуска:

| Файл запуска | Назначение |
| --- | --- |
| `TournamentProcessor.cmd` | Перетащите на него запись `.mp4` или `.mkv`. Он создаёт папку сессии рядом с видео (`<name>_TournamentSession\Output_Results\`) с Excel, CSV и `<name>_TournamentRaceResultsV1.json`. |
| `TournamentAnalysis.cmd` | Окно для того же анализа записанных видео, с несколькими видео или папкой на турнир ([ниже](#анализ-записей-после-вечера)). |
| `TournamentLive.cmd` | Захват в реальном времени во время вечера или воспроизведение видео: **Добавить видеофайл** (или добавьте устройство захвата), **Запустить все**, проверьте **Подтверждённое положение**, затем **Открыть экспорты**. Как передать сессию, см. [Из Tournament Live на сайт](#из-tournament-live-на-сайт). |
| `TournamentConnect.cmd` | Необязательное подключение к сайту (ниже). |
| `TournamentLiveCli.cmd` | Диагностика: обнаружение устройств, команды воспроизведения и результатов. Не замена окну Live. |

`TournamentTools.config.cmd` содержит локальные пути и языковые настройки. Сохраните его, папку сессий `TournamentLive\`
и ваши папки вывода, когда устанавливаете более новый пакет.

### Анализ записей после вечера

Используйте Tournament Live, когда захватываете вечер по ходу. Если вечер прошёл без него и у вас есть только
записи, проанализируйте их после вечера в окне **Tournament Analysis**:

1. Дважды щёлкните `TournamentAnalysis.cmd` в папке пакета.
2. **① Выбор записей**: **Добавить видео...** выбирает одну или несколько записей (`.mp4`, `.mkv`, `.mov`, `.avi`,
   `.ts`); **Добавить папку...** добавляет папку с записями одного турнира.
3. **② Выбор видео**: всё добавленное отмечено галочкой; снимите отметку с того, что не нужно анализировать (**Все**, **Нет**,
   **Очистить**).
4. **③ Запуск анализа**: проверьте **ID сессии** (заполняется по первому имени и дате; сохраняется
   с каждой гонкой) и **Папка результатов** (по умолчанию `<first name>_TournamentSession` рядом с первой
   записью), затем выберите **НАЧАТЬ АНАЛИЗ**. Окно выполняет ту же обработку, что и `TournamentProcessor.cmd`;
   журнал действий показывает её цветной вывод, индикатор запуска становится жёлтым, а **Отмена** прерывает её. Записи
   связываются в `Input_Videos\` папки результатов или копируются, если находятся на другом диске.
5. **🏁 Результаты**: когда появится **Завершено**, выберите **Открыть последний Excel** или **Открыть папку результатов**: `Output_Results\`
   содержит книгу Excel, CSV и `*_TournamentRaceResultsV1.json`. Проверьте гонки, затем импортируйте JSON
   на сайте, как описано выше.

Тексты следуют языку Windows (английский или нидерландский); `MK8DX_TOURNAMENT_LANGUAGE` в
`TournamentTools.config.cmd` переопределяет его. Чтобы показать другое изображение в баннере, укажите в `MK8DX_ANALYSIS_BACKGROUND`
в `TournamentTools.config.cmd` этот файл. Из клона `python -m tournament_processor.gui` открывает то же окно, если
установлены Tournament Processor и его ресурсы распознавания; нужен PySide6 (дополнение `gui` процессора), а
иначе или с `--classic-gui` открывается более простое окно Tkinter.

### Подключение к сайту (необязательно)

В PowerShell, в папке пакета:

```powershell
.\TournamentConnect.cmd sign-in                           # asks for the website address once, then browser sign-in
.\TournamentConnect.cmd server                            # shows the address
.\TournamentConnect.cmd server https://www.example.org    # changes it (asks for confirmation)
.\TournamentConnect.cmd tournaments                       # lists the nights you may deliver to
.\TournamentConnect.cmd target                            # night and group for Tournament Live's live feed (clear-target)
.\TournamentConnect.cmd send <name>_TournamentRaceResultsV1.json   # asks which night, then uploads
.\TournamentConnect.cmd sign-out
```

Используйте `http://127.0.0.1:<port>` (или `http://localhost:<port>`) только тогда, когда сайт работает на том же
компьютере с Windows, как в A1 и A3: простой HTTP принимается для этих адресов на этом ПК и ни для чего больше; любому
другому адресу нужен его доверенный HTTPS-адрес. Без терминала (например, из скрипта) `sign-in` ничего не спрашивает:
сначала задайте адрес командой `TournamentConnect.cmd server <address>`. Загрузки, ожидающие одного сервера, остаются при
этом сервере. Переданная гонка попадает во **Входящие результаты**; она никогда не публикуется автоматически.

### Из Tournament Live на сайт

1. В Tournament Live выберите **Подключиться к Tournament Manager** (позже **Сменить турнир**), завершите вход в
   браузере и выберите вечер в **Выбрать турнир**. Этот выбор — лишь предложение; его можно сделать до
   или после сессии.
2. Запустите источники (**Добавить видеофайл** или карта захвата, затем **Запустить все**). Tournament Live может сам
   добавить запомненную карту захвата как дополнительный источник в Группа 1. Если в Group 1 есть ещё и видео,
   **Запустить все** останавливается с сообщением *Перед нажатием START назначьте каждому сигналу ровно одну, у всех разную, группу текущего шага*: выделите дополнительный источник и выберите **Удалить выбранное** или дайте
   ему собственную группу и запустите снова.
3. На сайте откройте вечер, перейдите к шагу 5 (шагу 9 для финальных групп) и найдите сессию в разделе **Доступные записи Tournament Live**.
   Выберите её группу в **Привязать к группе**, затем **Привязать проверенную запись**. Гонки ждут как непринятые
   данные, пока вы их не примете.

### Подключение позже

Вечер, обработанный без подключения, полностью сохранён на вашем ПК: `Output_Results\` содержит книгу Excel, CSV
и `*_TournamentRaceResultsV1.json`. Tournament Live без подключения тоже записывает свою книгу Excel: когда вы
останавливаете источники, когда анализ завершается или когда вы закрываете окно, пока источники ещё работают (сначала
он их останавливает). Файлы остаются в `Live_Output\exports` (**Открыть экспорты**) после закрытия. Если Live аварийно
завершён до остановки источников, этой итоговой книги нет; записи остаются, и Tournament Analysis или Processor
создадут из них ту же книгу. Потом ничего не отправляется само; перенесите результат на сайт одним из
этих способов:

- В группе на сайте: **Запасной офлайн-вариант: импортировать сохранённый файл результатов Live / Processor** с JSON
  или импорт Excel для группы. Каждое распознанное имя сначала нужно сопоставить с игроком; импорт отклоняет группу,
  пока какое-либо имя не сопоставлено.
- Администратор: **Администрирование → Турниры → Импорт канонических результатов гонок**. Импортированные гонки остаются
  закрытыми, пока их не опубликуют.
- С помощью TournamentConnect: `.\TournamentConnect.cmd sign-in`, затем
  `.\TournamentConnect.cmd send <name>_TournamentRaceResultsV1.json`. Он спрашивает вечер, группу и номер
  первой гонки; гонки поступают во **Входящие результаты**. Если сайт недоступен, файл остаётся
  на месте; отправьте его позже ещё раз.
- В Tournament Live: если выбрать вечер через **Подключиться к Tournament Manager** после завершения сессии, эта
  завершённая сессия будет предложена вечеру. Загрузки, которые не удались, пока Live был подключён, сохраняются и отправляются
  снова, автоматически или через **Повторить загрузку**, только для того же аккаунта, в который выполнен вход. Сессия,
  запущенная в режиме **Работать офлайн**, не сохраняется для загрузки; для её файла используйте один из способов выше.

Вход добавляет две вещи: список вечеров, в которые вы можете передавать результаты, и поток Live во время вечера (`target`),
который отправляет каждую гонку в выбранную группу по мере того, как Tournament Live её распознаёт. В любом случае гонка
засчитывается только после того, как вы подтвердите её в разделе **Входящие результаты**.

### Проверка прочитанного

OCR может неверно прочитать имя, место или накопленные очки. Сравните каждую гонку с экраном или записью, прежде
чем подтвердить её. Одно известное ограничение: Tournament Live может экспортировать верный результат гонки с неверно
прочитанной суммой очков, а проверка на сайте не позволяет редактировать наблюдаемое имя или сумму (см.
[Tournament Live on a local laptop](../../../product/README_TOURNAMENT_LIVE_LAPTOP.md)).

Инструменты читают игру на 15 языках консоли. Tournament Live прошёл физический приёмочный прогон на скорости 1× с
пакетом v0.2.2: три ПК-источника воспроизводили записанные видео квалификации в собственные карты захвата
([issue #137](https://github.com/fromthelake/MK8DX-Ecosystem/issues/137)). Воспроизведение видео без карты захвата
не проверяет путь захвата.
