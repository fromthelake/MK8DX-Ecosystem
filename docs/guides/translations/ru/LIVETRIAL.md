# LiveTrial: запись гонок на время в Windows

*Это машинный перевод [английского руководства](../../LIVETRIAL.md); основной считается английская версия. Исправления приветствуются через форму issue «Translation correction».*

[Все руководства](../../../../README.md#get-started) · [README компонента LiveTrial](../../../../apps/timetrials-desktop/README.md)

LiveTrial — это программа для Windows, которая следит за вашими гонками на время через карту захвата или читает
записанные видео, распознаёт каждый заезд (общее время и время кругов, персонажа и сборку карта, призрака) и сохраняет
его на вашем ПК вместе с клипом. После того как вы один раз войдёте в аккаунт, она может отправлять результаты на сайт
вашего сообщества. Результаты, которые пока нельзя отправить, ждут на ПК.

## Без сайта сообщества

LiveTrial работает и сам по себе. Захват, анализ видео, **История заездов**, клипы и исправления работают локально.
Заезды, записанные без аккаунта, остаются только на этом ПК, пока вы не отправите их через **Отправить как <account>**.
Вкладкам **Мои рекорды**, **Место** и **Сборка** нужно сообщество, в которое выполнен вход.

## Требования

- Windows на x86-64 (проверено на Windows 11). Около 1 ГБ для программы плюс место для ваших записей.
- Для захвата в реальном времени: карта захвата, которую Windows показывает как видеоустройство, с её драйвером, и
  **FFmpeg** (бесплатный, не входит в комплект из-за его лицензии; см. шаг 4 ниже). Для видеофайлов: ни карта
  захвата, ни FFmpeg не нужны.
- Для отправки результатов: адрес сайта вашего сообщества и аккаунт на нём (см. [Игроки](PLAYERS.md)).
  На том же компьютере, что и локальная пробная установка, работает `http://127.0.0.1:<port>`; в остальных случаях
  используйте доверенный HTTPS-адрес.

## Установка

1. На странице [GitHub Releases](https://github.com/fromthelake/MK8DX-Ecosystem/releases) проекта (пакеты прикреплены
   к каждому релизу) скачайте `desktop-client-….zip` и `SHA256SUMS.txt`. Имея клон, вы можете вместо этого собрать
   тот же пакет сами: [Client builds](../../../CLIENT_BUILDS.md#livetrial-windows). Проверьте его в PowerShell:
   `Get-FileHash '.\desktop-client-<version>.zip' -Algorithm SHA256` и сравните значение целиком.
2. Распакуйте **весь** ZIP в собственную папку, например в «Документы». Сохраните структуру папок: пакет содержит
   собственную среду выполнения Python, движок распознавания и ресурсы игры.
3. Дважды щёлкните `LiveTrial.exe`. Панель открывается в отдельном окне (Edge, иначе Chrome, иначе ваш браузер по
   умолчанию). Анализ видео работает сразу.
4. Для захвата в реальном времени один раз установите FFmpeg. Проще всего: откройте PowerShell и выполните `winget install Gyan.FFmpeg`,
   затем закройте и снова запустите LiveTrial, чтобы он увидел новый PATH. Без winget скачайте сборку для Windows
   (например, release-архив gyan.dev, ссылка на который есть на [ffmpeg.org/download.html](https://ffmpeg.org/download.html)),
   распакуйте её и скопируйте `bin\ffmpeg.exe` в `%LOCALAPPDATA%\MK8DX\LiveTrial\tools\ffmpeg\bin\`. Если FFmpeg нет,
   **Начать захват** сообщит об этом и покажет эти шаги.

## Подключение к сообществу

1. Откройте **Настройки**. Введите адрес вашего сообщества в поле **Адрес сайта сообщества** (например,
   `https://www.example.org`) и выберите **Сохранить сервер**. LiveTrial перезапустится сам; не закрывайте его.
2. После перезапуска убедитесь, что в настройках указан именно ваш адрес, затем войдите через меню аккаунта (код по
   почте, ссылка по почте или подтверждение на сайте).
3. Если автоматический перезапуск не удался, выберите в приложении **Выйти из LiveTrial**, дождитесь, пока он закроется,
   и снова запустите `LiveTrial.exe`. Закрыть только окно недостаточно: LiveTrial может продолжать работать в фоне.

Аккаунты и ожидающие заезды хранятся отдельно для каждого сервера: смена сервера никогда не отправляет старые заезды
новому сообществу. Никогда не вводите в LiveTrial адрес локального почтового ящика или внутренний адрес сервера.

## Подключение позже

Можно сначала записывать, а присоединиться к сообществу позже. Что происходит с заездами, которые уже есть на этом ПК:

- **Выберите сообщество до того, как начнёте записывать.** Заезды хранятся по серверам. Заезды, записанные до того, как
  вы сохранили адрес сообщества, или пока было выбрано другое сообщество, остаются при том сервере и никогда не
  предлагаются новому. Чтобы перенести такую запись, после подключения снова запустите **Анализировать видео** для её
  видеофайла.
- **Заезды, записанные без аккаунта**, не отправляются, когда вы позже входите. Выберите **Отправить как <account>** у
  одного заезда (в разделе **История заездов** или в строке после гонки) или в строке **Нет аккаунта** списка ожидания
  (счётчик вверху), чтобы передать их все аккаунту, в который выполнен вход. Они попадают к игроку этого аккаунта; без
  такого выбора ничего не назначается.
- **Заезды, записанные при выполненном входе**, всегда уходят с тем же аккаунтом. **Отправить сейчас** отправляет все
  ожидающие заезды, каждый со своим аккаунтом; заезд, чей аккаунт вышел из системы, ждёт, пока этот аккаунт снова не войдёт.
- **Каждый заезд хранится один раз.** У каждого заезда свой идентификатор отправки, и сайт не принимает вторую
  копию того же заезда.
- **Клипы и видео остаются на этом ПК.** На сайт уходит только результат (времена, трасса, сборка); загрузка на
  YouTube — отдельный необязательный шаг.

## Использование

- **Начать захват**: выберите карту захвата. Сначала LiveTrial показывает с неё один неподвижный кадр, чтобы вы могли
  убедиться, что это нужное устройство. Затем вкладка **Live** показывает изображение и каждый распознанный заезд.
- **Анализировать видео**: выберите файл `.mp4`/`.mkv` (он копируется в
  `%LOCALAPPDATA%\MK8DX\LiveTrial\videos`), и LiveTrial обработает его как захват.
- После каждой гонки строка **Последняя гонка** показывает, где находится заезд: на сайте, сохранён и ждёт отправки
  (**Отправить сейчас**) или только на этом ПК (**Отправить как <account>**).
- **История заездов** показывает каждый заезд с его клипом. Вы можете исправить распознавание; исправление сохраняет новую
  версию и оставляет прежнюю.
- Автоматическая отправка по умолчанию выключена; включите её в настройках. Заезд всегда сначала сохраняется локально.

Укажите **Язык вашей Switch** в настройках, если язык консоли отличается от языка панели.

## Проблемы

- Не тот сайт, или вход открывает не тот сайт: закройте LiveTrial через **Выйти из LiveTrial**, запустите его снова и
  проверьте адрес в настройках. Возможно, LiveTrial всё ещё запущен под другой учётной записью Windows на том же ПК.
- Устройство захвата не отображается: проверьте USB-подключение и драйвер, подождите несколько секунд и попробуйте снова.
- Ошибки распознавания: исправьте заезд в истории заездов перед отправкой. Распознавание никогда не заменяет проверку
  собственного результата.

LiveTrial работает только в Windows; сборки для macOS или Linux нет. Чтобы собрать его самостоятельно, см.
[Client builds](../../../CLIENT_BUILDS.md).
