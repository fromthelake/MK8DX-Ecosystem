# プレイヤー向け：ウェブサイトと Android アプリ

これは英語版ガイド（[PLAYERS.md](../../PLAYERS.md)）の機械翻訳です。内容は英語版が正となります。翻訳の誤りは「Translation correction」の Issue フォームからお知らせください。

[すべてのガイド](../../../../README.md#get-started)

必要なのは、自分のコミュニティの MK8DX ウェブサイトのアドレスです。たとえば `https://www.example.org`。
コミュニティはそれぞれ独自のインストールを運営していて、アカウントと結果もコミュニティごとに別々です。
アドレスやアカウントについては、自分のコミュニティの運営者に聞いてください。ウェブサイトを使うだけなら、
何もインストールする必要はありません。

## ウェブサイト

### サインイン

1. コミュニティのアドレスを開き、アカウントのアイコン（右上）を選んで、**サインイン** を選びます。
2. メールアドレスを入力し、**リンクをメールで送る** を選びます。メールを開いてリンクをたどります。パスワードは
   ありません。リンクは 1 回だけ使え、期限があります。使えない場合は新しいリンクを依頼してください。
3. 初回は、リンクから 3 ステップの初期設定が直接開きます。ステップ 1 の **すでにこのウェブサイトに載っていますか？**
   では、自分のタイムアタックのタイムがすでにサイトに載っているか、サイトに載っている大会に参加したことがあるかを
   聞かれます。載っている場合、ステップ 2 で自分にあたるプレイヤーを探し、自分のアカウントに結び付けるよう申請
   できます。そうした申請は、結び付けられる前に管理者かその夜の大会ディレクターが確認します。名前だけで結び付け
   られることはありません。載っていない場合は、ステップ 2 で自分のプレイヤーが作られます（ディレクターだけが
   プレイヤーを作るコミュニティでは、代わりに誰に頼めばよいかが説明されます）。ステップ 3 では、飛ばしてもよい
   任意の設定がいくつか出てきます。

アカウント（サインインに使うメールアドレス）とプレイヤー（ランキングに載る名前）は別のものです。

### タイムアタックのタイムを投稿する

- **タイムを投稿**（上部のバー）、または **コース** → コース → **タイムを投稿**：150cc または 200cc のタイムを
  入力し、確認画面で値を確かめてから公開します。
- **スキャンする**：スマートフォンやタブレットで `<your community address>/scanner/` を開きます。カメラをテレビの
  結果画面に向けるか、写真やスクリーンショットで **画像をアップロード** を選びます。スキャナーはタイム、ラップ、
  そして見えていればキャラクター、カスタマイズ、国旗を読み取ります。送信する前にすべての値を確認してください。
  認識は間違うことがあります。カメラには信頼された HTTPS アドレスが必要です（`localhost` でも使えます）。
  画像のアップロードはどこでも使えます。
- コミュニティのルールによって、投稿はすぐに公開されることも、管理者の確認を待つこともあります。管理者は
  公開済みのタイムを修正したり取り下げたりできます。

### 自分の成長を追う

**コース**、**ランキング**、**記録** では、自分のベストタイムとラップを、コミュニティ、自分で選んだライバル、
Nintendo のスタッフゴースト、世界記録と並べて表示します。**組み合わせ** はキャラクターとカスタマイズの組み合わせ
選びを手伝い、**コミュニティ** は他のプレイヤーを、**大会** は公開された大会の夜、順位、レポートを表示します。
誰かが自分の公開済みのタイムを上回ると、通知（ベル）が届きます。コミュニティが設定していれば、ウェブサイトは
ブラウザーのプッシュ通知も送れます。アカウントの設定でオンにしてください。

ウェブサイトはゲームと同じ 15 言語で使えます（設定で自分の言語を選んでください）。英語とオランダ語はレビュー
済みです。他の 13 言語は機械翻訳で、修正を歓迎します。編集するファイルは
[Change UI text and translations](../../../DEVELOPMENT.md#change-ui-text-and-translations)、プルリクエストについては
[Contributing](../../../../.github/CONTRIBUTING.md) を参照してください。

## Android アプリ

アプリでは、スマートフォン上でのより速いスキャン、自分のタイム、通知が使えます。アプリは任意です。

### 必要なもの

- Android 8.0 以降。arm64 のスマートフォンを推奨します。リリース版 APK は大きい（約 530 MB）ので、
  インストール中は約 1 GB の空きを確保してください。
- アプリがつながれるコミュニティ：信頼された HTTPS アドレスのある **オンラインコミュニティ**、または同じ Wi-Fi
  にある **自宅またはクラブのインストール**（A2）。コンピューター内だけのアドレス（`http://127.0.0.1:…`）は
  アプリでは使えません。

### インストール

1. コミュニティの **アプリを入手** ページにダウンロードがあれば、そこから APK を入手します（表示するには
   サインインが必要です。それがコミュニティの対応しているビルドです）。または、プロジェクトの
   [GitHub Releases](https://github.com/fromthelake/MK8DX-Ecosystem/releases) ページから
   `mk8dx-android-release-….apk` を入手します。リポジトリのクローンがあれば、APK を自分でビルドすることもできます：
   [Client builds](../../../CLIENT_BUILDS.md#android)。
2. 同じリリースの `SHA256SUMS.txt` とファイルを照合します（コンピューターで：PowerShell では `Get-FileHash`、
   Linux では `sha256sum`、macOS では `shasum -a 256`）。
3. APK をスマートフォンにコピーし、**ファイル** または **ダウンロード** から開きます。Android が、そのアプリからの
   インストールを許可するよう求めます。許可するのはこの確認済みのファイルだけにして、必要ならその後でオフに戻してください。

これは Play ストアのアプリではありません。以前に公開された APK はデバッグ用のビルドキーで署名されていました。リリース版
APK は、メンテナーが保持している鍵を使っています。まだ送信していない結果を保存し、このリリース版をインストールする前に、
以前のデバッグ版 APK を一度アンインストールしてください。同じリリースキーで署名された今後の APK は、そのまま上書き
アップデートできます。コミュニティの APK や自分でビルドした別の鍵の APK に切り替える場合も、アンインストールが必要です。

### 最初の起動

アプリは **コミュニティを選択** で開きます。アプリがスマートフォンの言語に対応していれば、その言語で表示されます。別の
言語を選ぶには、上部の **言語 / Language**（地球のアイコン付き）をタップします。アプリはその選択を覚えています。その後、
アプリは 1 つだけ質問します：あなたのコミュニティはどのように遊んでいますか？わからない場合は、
コミュニティの運営者に聞いてください。

- **自宅またはクラブ**（A2、MK8DX がそこのコンピューターで動いています）：**QR コードをスキャン** をタップし、管理者が
  そのコンピューターで表示するか紙で配る **Prepare a device**（機器の準備）カードを読み取ります。スマートフォンは同じ
  Wi-Fi につながっている必要があります。するとアプリにインストールのアドレスと鍵が表示されます。これらは **Prepare this
  device**（この機器を準備）ページの **Full fingerprints**（すべてのフィンガープリント）にも載っています。一致したら
  **接続** をタップします。インターネットは不要です。詳しい手順：
  [A2 ガイドの第 7 章](../../../install/translations/ja/A2_HOME_GUIDE.md#7-android-アプリと-livetrial)。
- **オンラインコミュニティ**（インターネット上のウェブサイト）：ブラウザーで開くときのアドレスを入力します。たとえば
  `https://www.example.org`（パスや末尾のスラッシュは付けません）。**保存** をタップします。うまくいかない場合は、
  スマートフォンのブラウザーで同じアドレスを開いてください。証明書の警告なしに開く必要があります。

自宅やクラブ（A2）では、まず 16 文字のインストール確認コードを照合して **接続** をタップします。その後、アプリの **証明書を保存**、**設定を開く**（CA 証明書としてインストール）、**サインインカードをスキャン** の順に進み、アプリ内でサインインします。ブラウザーのデバイスコードは不要です。オンラインコミュニティでは人型アイコンから **サインイン** を選び、ブラウザーで承認します。

### アプリの使い方

アプリの上部には、ロゴ（ホームに戻る）、使っているコミュニティの名前が書かれた **コミュニティチップ**、ベル、自分の名前が
あります。自分の名前を押すと **あなた** が開きます。そこには **プレイヤーを切り替え** の付いた自分のプレイヤーと、
**自分のタイム**、**記録**、**ライバル** のタブがあり、その下に **設定** の行があります。

- **複数のコミュニティ**：コミュニティチップをタップすると **コミュニティ** が開きます。使用中のコミュニティは緑色です。
  **コミュニティを切り替え** でワンタップで別のコミュニティに替わり、**このスマートフォンから削除** で 1 つを削除します（送信待ちのものが
  なくなってからのみ）。**コミュニティを追加** で最初の起動時の画面がもう一度開きます。各コミュニティは、それぞれの
  サインイン、未送信の記録、そして自宅やクラブではそれぞれの信頼設定を保持します。コミュニティどうしで自動的に何かが移る
  ことはありません。管理者がコミュニティに名前を付けている場合、アプリはアドレスの代わりにその名前を表示します。
- **自分のタイム** は 1 つの一覧です。まず通算の数字、続いてコースとクラスごとに自己ベストが 1 行ずつ並びます。行を
  タップすると以前の記録が表示され、記録の **⋯** から **詳細**、**編集**、**取り下げ**、
  **別のコミュニティへ持っていく…** を選べます。
- **インターネットなしの場合**：アプリはコミュニティごとに、自分のタイムとライバルのベストタイムのコピーを保持し、
  「オフライン — 最終更新 …」と表示します。
- **送信待ち**：まだスマートフォンにしかない記録は、ホームとあなたにオレンジ色のバナーで表示されます。それをタップするか、
  設定 › **このスマートフォンに保存** で確認できます。
- **設定** は **プレイヤー**、**アプリ**、**コミュニティ**、**このアプリについて** に分かれていて、変更はそれぞれ自動的に
  保存されます。言語はアプリの中にあります。**アプリを入手** と **このスマートフォンに保存** はコミュニティの中に、
  **テストスキャンを実行** はこのアプリについての中にあります。

### タイムを別のコミュニティへ持っていく

複数のコミュニティに所属している場合、タイムを別のコミュニティでも有効にできます。記録の **別のコミュニティへ持っていく…**、
または自分のタイムの通算の数字の下にある **自分のベストタイムを持っていく** を使います（相手のコミュニティにすでに自分の
より良いタイムがあるコースは飛ばされます）。コピーは、相手のコミュニティでサインインするまで待機します。決めるのは
**受け取る側** のコミュニティです。既定では他所からのタイムは受け付けませんが、管理者が 1 件ずつ先に承認するように
することも、他のタイムと同じように受け付けることもできます。持ち込まれたタイムには、必ずどこから来たかが表示されます
（「… から持ち込み · 元の日付 …」）。同じ元のタイムが取り込まれるのは 1 回だけです。同じタイムの場合は、既存の記録に
足りなかった項目が補われるだけです。

### 通知

アプリの通知は、コミュニティの受信箱から取得されます。Android の通知の許可と、アプリ自体のスイッチの両方がオンに
なっている必要があります。

## 困ったときは

- サインインのメールが届かない：迷惑メールフォルダー、入力したアドレスが正確かを確認し、新しいリンクを依頼してください。
  ローカルの試用インストールでは、メールは自分のメールボックスではなく、ローカルのテスト用受信箱に届きます。
- 申請が *現在、申請の操作が多すぎます…* で拒否された：表示された時間だけ待ってから、もう一度お試しください。1つのアカウントで同時に決定待ちにできる申請は最大5件です（1人のプレイヤーに対しては、全アカウント合わせて最大5件）。上限に達したら、保留中の申請が処理されるまで待つか、**この申請を取り下げる** で1件取り下げてから、もう一度お試しください。
- コミュニティのサイトで何かおかしい：まずそのサイトの運営者に聞いてください。ソフトウェア自体のバグは、プロジェクトの
  Issue で報告できます。[SUPPORT.md](../../../../.github/SUPPORT.md) を参照してください。サインインのリンクや他の人の名前は
  決して投稿しないでください。
