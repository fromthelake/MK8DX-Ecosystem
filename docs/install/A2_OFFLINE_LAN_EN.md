# A2 offline LAN

This page was the orientation for the earlier A2 test installations. The A2 route is now released with a
guided setup in the browser. Use the step-by-step guide instead:

- English: [MK8DX at home or at your club](A2_HOME_GUIDE_EN.md)
- Nederlands: [MK8DX thuis of op de club](A2_THUIS_HANDLEIDING_NL.md)
- Illustrated HTML version of both: `docs/install/guide/en.html` and `nl.html` (also inside the A2 package,
  and opened by the setup wizard's **Manual** link).

It covers installing, sign-in cards, phones and PCs, the Android app and LiveTrial, nightly backups,
restoring on a new computer, a fixed address and a new network address, and updates.
