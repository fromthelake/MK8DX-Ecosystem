Это машинный перевод английского руководства; основной считается английская версия. Исправления приветствуются через форму issue «Translation correction».

Выберите один способ. Полное руководство описывает все шаги на русском языке; для A2 есть также иллюстрированное руководство. Скачайте пакет и SHA256SUMS.txt со страницы выпусков. «Source code (zip)» не является установочным пакетом.

[Полное руководство](MK8DX_User_Guide.txt) · [Иллюстрированное руководство A2](A2_HOME_GUIDE.md) · [Пакеты и контрольные суммы](https://github.com/fromthelake/MK8DX-Ecosystem/releases/latest)

| Способ | Для чего и где | Глава |
| --- | --- | --- |
| A1 | Попробовать на одном компьютере Windows или Linux с Docker (x86-64). | 1 |
| A3 | Один компьютер Windows без Docker; XAMPP и Node.js. | 2 |
| A2 | Домашняя или клубная сеть; после настройки интернет не нужен. | 3; [Иллюстрированное руководство A2](A2_HOME_GUIDE.md) |
| B2 | Публичный сайт на хостинге с Node.js и MariaDB/MySQL. | 4 |
| B1 | Публичный сайт на Linux VPS с Docker (x86-64). | 5 |
