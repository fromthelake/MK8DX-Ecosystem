これは英語版ガイドの機械翻訳です。内容は英語版が正となります。翻訳の誤りは「Translation correction」の Issue フォームからお知らせください。

方法を一つ選びます。完全版ガイドには日本語ですべての手順があり、A2 には画像付きガイドもあります。リリースページからパッケージと SHA256SUMS.txt をダウンロードしてください。「Source code (zip)」はインストール用パッケージではありません。

[完全版ガイド](MK8DX_User_Guide.txt) · [画像付き A2 ガイド](A2_HOME_GUIDE.md) · [パッケージとチェックサム](https://github.com/fromthelake/MK8DX-Ecosystem/releases/latest)

| 方法 | 用途と環境 | 章 |
| --- | --- | --- |
| A1 | Docker を使って Windows または Linux の 1 台で試す（x86-64）。 | 1 |
| A3 | Docker を使わない Windows の 1 台。XAMPP と Node.js を使います。 | 2 |
| A2 | 自宅やクラブのネットワーク。設定後はインターネット不要。 | 3; [画像付き A2 ガイド](A2_HOME_GUIDE.md) |
| B2 | Node.js と MariaDB/MySQL に対応したホスティング上の公開サイト。 | 4 |
| B1 | Docker を使う Linux VPS 上の公開サイト（x86-64）。 | 5 |
