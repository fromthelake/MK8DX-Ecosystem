이 문서는 영어 안내서를 기계 번역한 것입니다. 기준은 영어판이며, 수정 제안은 "Translation correction" 이슈 양식으로 보내 주세요.

설치 경로 하나를 선택하세요. 전체 안내서에 모든 단계가 한국어로 설명되어 있고 A2에는 그림 안내서도 있습니다. 릴리스 페이지에서 패키지와 SHA256SUMS.txt를 내려받으세요. “Source code (zip)”은 설치 패키지가 아닙니다.

| --- | --- | --- |
| A1 | Docker로 Windows 또는 Linux 컴퓨터 한 대에서 시험합니다(x86-64). | 1 |
